# Adopt a professional posture in challenging situations

Take one's work environment into account, participate proactively in technical achievements, and collaborate actively and in a motivating manner.

---

??? example "W1 · TEXTurePaper environment blocker"
    **Action:** Resolved a complex dependency and environment setup issue with the TEXTurePaper repository.

    **Justification:** Instead of abandoning the solution at the first obstacle, the approach was to check existing issues in the repo, identify compatible dependency versions by timeline and isolate the environment in Docker.

    **Reference:** [Week 1](../../journal/week1.md)

??? example "W2 · Unprepared client meeting"
    **Action:** Identified the failure of the CEO meeting (no leader, no preparation).

    **Justification:** Acknowledged a failure and proposed a provinding changes ideas (vulgarize, prepare decision points, assign accountability).

    **Reference:** [Week 2](../../journal/week2.md)

??? example "W3 · Recurring client meeting failures"
